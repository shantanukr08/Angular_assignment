# Angular Dashboard Assignment

This project is a dashboard built with **Angular 18**, based on the technical task requirements.  
It matches the provided PDF screenshots closely, using **pure SCSS** without any external UI frameworks.

## 📋 Features

- Sidebar with navigation icons
- Topbar with search input and profile picture
- Summary Cards showing KPIs
- Custom Grid (Add / Edit / Delete rows locally)
- Toast Notifications for actions
- Loader Spinner during API fetch
- ApexCharts integrated for chart visualization
- Modular structure with reusable components
- Clean SCSS styling (no Tailwind, Material, or Bootstrap)

---

## 🔥 Tech Stack

- Angular 18
- TypeScript
- SCSS (pure)
- RxJS
- ApexCharts (via `ng-apexcharts`)
